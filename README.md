# ThinkFit Club website

A responsive, single-page marketing site for ThinkFit Club's three Chicagoland locations.

## Preview

Open `index.html` in a browser, or serve the `thinkfit` folder with any static web server.

## Structure

- `css/styles.css` — core visual design
- `css/responsive.css` — tablet and mobile layouts
- `js/main.js` — navigation, form, and carousel behavior
- `js/testimonials.js` — testimonial content
- `assets/` — organized brand and photography files

The free-pass form currently provides a front-end success state. Connect it to your preferred CRM or form service before launch.
